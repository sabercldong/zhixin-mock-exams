# 第028套整理文件

正式PDF保存在output，可编辑正文保存在markdown，TikZ及单图矢量PDF、PNG保存在figures。原始试卷不修改，既有辅助资料不删除、不转移。

本套逐套验收已通过：试卷版9页，学生详解版67页（正文66页），教师备课版79页（正文78页）；31幅重绘图，8题独立计算核验。三版本155页总览及42页高清复核记录已保存，批次统一复审尚待完成。

日常正文修改入口：markdown/蔡题028_教师备课.md。学生版只提取每题前五模块，试卷版只提取题干；不要独立修改派生版本后期待自动回写。教师版九模块，学生版五模块，核心解答保持一致。

重建命令：

    python3 scripts/build_all.py

构建依次进行独立计算核验、图稿渲染、Markdown派生、Pandoc—XeLaTeX编译及技术检查。每次PDF校验和改变后，应重新审阅实际PDF并更新preview/formal/visual-review.json，不能用旧审阅记录授权新PDF通过最终验收。

drafts为逐题工作稿。只有明确希望用工作稿覆盖教师主文件时，才使用：

    python3 scripts/build_all.py --from-drafts

图稿修改入口：figures/题01_图稿源文件.tex至题08_图稿源文件.tex。各文件含该题全部独立TikZ图页，脚本导出既定名称的单图；正式正文不展示代码。

版式固定为A4、12pt、四边22mm、行距1.24、段距0.35em。仅八题之间七处分页；有限逻辑块只保持推导与结论相邻，不扩大行距或段距补页。

本套没有手写答案，按已获授权独立推导。第1题原件2v经用户确认改为2f。第4题明确声明准静态等摩擦模型；第6题区分动量载荷与完整弯管载荷、保留旁路长度比；第3题区分瞬时零速与最终静止，第7题区分事件坐标与光信号接收。

核对记录.md保存逐题资料索引与物理边界。build/strict-quality.json保存页数、三种字符口径、逐题正文量、101同口径对照及验收结果。preview/formal和preview/figures保留实际PDF审阅及图稿检查依据。
