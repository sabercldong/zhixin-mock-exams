# 第2题

建立空间直角坐标系 $xyz$。在 $(0,0,h)$ 和 $(0,0,-h)$ 处固定两个小磁铁，将它们视为磁偶极子，磁矩均沿 $+z$ 方向，大小均为 $m_0$。在原点有一个质量为 $m$、电荷量为 $q$ 的粒子，初速度为 $v_0\boldsymbol e_x$。

# 第3题

考虑一个三星系统中的行星。三颗恒星的质量均为 $m$，两两间距均为 $l$，绕共同质心以恒定角速度转动。万有引力常量为 $G$。只考虑平面内运动。

（1）求恒星绕共同质心转动的角速度 $\omega_0$。

（2）设一颗质量远小于 $m$ 的行星与恒星以相同角速度 $\omega_0$ 绕质心转动。求在恒星的转动参考系中，行星可能存在的全部平衡位置，不要求讨论稳定性。

（3）设一颗质量远小于 $m$ 的行星在平均距质心 $R\gg l$ 的远处，绕质心缓慢作近似圆周运动。仅考虑三星非轴对称引力场引起的受迫波动，不计自由偏心分量。保留首阶非零小量，计算行星到质心的距离波动范围。

第（3）问不计自由偏心分量，所求波动范围为受迫距离的最大值与最小值之差；平均半径及平均转速的修正吸收到基本圆轨道中。

题目另附非考试情景：设一颗质量远小于 $m$ 的行星，在距某颗恒星 $r\ll l$ 的位置附近，绕该恒星快速作近似圆周运动。在恒星的旋转参考系中，保留首阶非零小量，计算行星到共同质心的距离波动范围。

# 第6题

惯性约束是实现受控核聚变的一种设想。采用以下简化模型讨论球形燃料的压缩过程：初始燃料为均匀等离子体球，原子核数密度为 $n_0$，温度为 $T_0$，半径为 $r_0$，每个原子核的质量为 $m_0$，按原子核计的摩尔定容热容为 $C_v$，满足理想气体状态方程。

用超强激光脉冲照射小球，使表面厚度为 $\alpha r_0$ 的一层燃料突然向内、向外运动，取 $\alpha=0.02$。假设这一表层中一半原子核以速率 $v_0$ 沿垂直表面的方向向内运动，压缩内部等离子体；$v_0$ 远大于热运动速率，不计表层原子核的热运动动能。

假设内部等离子体始终保持均匀球形，压缩时满足 $PV^\gamma=\text{常量}$，其中 $\gamma=5/3$。内部持续被压缩，直到向内运动的表层速度几乎为零。估算此时内部小球的温度 $T_1$ 和原子核数密度 $n_1$。

# 第7题

# 第8题

S. Adler、M. S. Atiya 等人报道了实验中对 $K^+$ 介子衰变的观测，并测量了衰变 $K^+\to\pi^++\mu^++\mu^-$ 的分支比。该报道发表于1997年。设 $K^+$、$\pi^+$ 的静止质量分别为 $m_K,m_\pi$，$\mu^+$ 与 $\mu^-$ 的静止质量均为 $m_\mu$，且 $m_K>m_\pi+2m_\mu$。考虑一个在实验室参考系中静止的 $K^+$ 发生上述衰变，光速为 $c$。

（1）求 $\pi^+$ 可能具有的最大动量大小 $p_{\pi\max}$，用 $m_K,m_\pi,m_\mu,c$ 表示。

（2）以 $p_x,p_y,p_z$ 为动量空间坐标。已知 $\boldsymbol p_\pi=(-p_0,0,0)$，求 $\mu^+$ 可能具有的动量范围，写出 $p_x,p_y,p_z$ 满足的方程，用 $p_0,c,m_K,m_\pi,m_\mu$ 表示。

（3）在第（2）问的条件下，求 $\mu^+$ 与 $\mu^-$ 两个非零动量的出射方向之间的最大夹角 $\theta$，用所给量表示相应的 $\cos\theta$。若临界情形只有上确界而没有可达到的最大值，须说明。
