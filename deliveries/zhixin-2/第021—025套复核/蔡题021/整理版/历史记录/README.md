## 源文件与重建

- 可继续编辑的教师主文件：markdown/蔡题021_教师备课.md。
- 对应学生版、试卷版：markdown/蔡题021_学生详解.md、markdown/蔡题021_试卷.md。
- 分题写作稿：drafts/question-01.md至question-08.md。教师主文件与分题稿均保留。
- 35幅渲染图及8份TikZ多图源码：figures/。
- 三版本编译源文件、日志、核验报告：build/。
- 固定版式模板：latex/template.tex；构建入口：scripts/build_all.py。
- 原始资料分栏、图稿预览、正式PDF总览和高清检查：preview/。
- 物理核验：scripts/verify_physics.py；严格验收：scripts/quality_check.py。
- 源题疑点、修复内容及物理证据：核对记录.md。

在本“整理版”目录中运行：

```sh
python3 scripts/build_all.py
```

此入口以已保存的教师主文件为准，提取学生前五模块及试卷题干。仅当明确选择从分题稿重新整合时使用：

```sh
python3 scripts/build_all.py --from-drafts
```

第二种方式会重新生成教师主文件；编辑主文件后不要误用它覆盖主文件的新改动。重新构建后，旧的视觉验收记录将因PDF或图稿校验和改变而失效，必须重新实际审图，不能仅更新哈希。
