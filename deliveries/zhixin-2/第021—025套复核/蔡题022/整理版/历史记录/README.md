## 文件与重建

markdown保留三版本可编辑源文件。通常修改markdown/蔡题022_教师备课.md，然后运行python3 scripts/build_all.py，学生版和试卷版按统一规则派生。仅在需要重新汇入分题工作稿时运行python3 scripts/build_all.py --from-drafts；此选项会重新生成教师主文件，使用前应核对其中是否有未同步到drafts的编辑。

figures保留TikZ、单图PDF和PNG；latex保留模板；build保留三版本LaTeX、日志、计算核验和质量报告；preview保留原件读取、总览和高清审图文件。所有原始及辅助文件保留，不删除或转移。重建后须重新检查变动页面，旧视觉验收记录不能直接用于改动后的成品。
