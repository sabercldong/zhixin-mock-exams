## 资料与模型限定

原始试卷为2页，8题及全部分问已逐页核对。本套没有手写答案，按用户已确认的第028—021套约定独立推导，不声称依据不存在的答案。原始PDF保持不动。

本轮针对第1、6、8题询问过是否进一步改写题干，尚未收到答复，因此没有把这些选择视为已批准。当前正式版保留原问的核心表述，并通过条件说明及解析区分下列问题；如后续明确改写，只更新整理版，不改原件。

- 第1题无耗散不能自动达到吸引性稳定振动；无回复力时给出一般初值解及选定周期特解。电阻可忽略不等于自感可忽略，电压驱动另列保留自感的结果、相位与共振限制。
- 第2题光子端点使用整个反冲系统的最小不变质量，保留反冲能；忽略中微子静质量时端点为可逼近的上确界。最大频移需要速度和发射方向的采集条件；真实质量与误用静止公式得到的表观质量分开。
- 第3题两已知投影不必同频，四种候选形状均能构造。辅助投影坐标与真实平面通过可逆剪切变换联系；有限抛物线弧不写成无界运动。
- 第4题整个制冷循环与两热源有热交换，不是整个循环绝热；采用可逆Carnot制冷极限。最低可维持室温通过漏热与抽热平衡求得，并核对稳定性、根的选择及开尔文温标。
- 第5题两次空气侧反射均为凸面反射，逐次重置沿传播方向的局部斜率；鬼影直径56D、中心距33f|α|只在近轴及不截光条件下成立，不把鬼影中心与正常像点的间距34f|α|混为一谈。
- 第6题按向量静摩擦约束求最大可支撑静力载荷；它不保证实际首次局部滑动一定发生于此。构造两个满足相同末端最大拉力的不同静力张力分布，证明现有条件不能唯一决定实际滑动分界；30°只对应明示的那一条分布的平台边界。
- 第7题中心力方向与法线一般不同，必须保留投影；双焦点几何路线与极坐标反演分别得到平方反比律。长短轴顶点、曲率、角动量及周期关系逐项核对。
- 第8题约束为可维持粒子在柱面上的光滑径向约束。严格等螺距螺旋、连续绕轴、轴向反向、闭合及临界分离轨道分别判断；零初始轴向速度时弱场与强场都存在闭合分支，临界等号不闭合。
