# 使用说明

每套的PDF目录含试卷、学生详解、教师备课三版。Markdown保留题面、模块与图稿引用；LaTeX使用相对路径，可在对应latex目录编译。figures目录含16份独立矢量图、PNG预览、独立TikZ片段和图稿主文件。

以教师Markdown为编辑入口。重建脚本同步学生版前五个模块和题面版，并保留每套七处题间手动分页。题内的needspace只帮助标题、公式与解释相邻，不改变字号、行距或页边距。模板为A4、12pt、22mm页边距、1.24行距。

依赖：Python 3、PyMuPDF、Pillow、NumPy、SciPy、SymPy、pandoc、qpdf，以及支持ctex和TikZ的XeLaTeX环境。本机已有这些依赖。重建命令在本目录运行：

```sh
python3 重新生成.py 47 46 45 44 43 --figures --documents
```

只改文字时使用--documents；改图时先改图稿主文件，再用--figures --documents。独立tikz片段用于复用，不会自动合并回主文件。重新生成后应重新检查图文对应、编译日志和分页。数学核验脚本在验证/数学核验中；数值断言各有明确范围，不能代替未证明的物理结论。

新增变式的额外假设已在正文中注明。第045套第6题原模型的热力学积分性问题保留为明确限制；另给一致对照模型，不把原题形式循环当作真实可逆热机。原卷索引保存来源路径与哈希，原卷PDF和页面副本仅用于对照。
