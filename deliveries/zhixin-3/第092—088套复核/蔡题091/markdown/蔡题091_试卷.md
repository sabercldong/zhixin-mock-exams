# 第 1 题

两面墙之间水平固定一根光滑杆，杆上套有一个质量为 $m$ 的小环。小环通过一根长为 $l$、不可伸长且质量不计的细线连接一个质量为 $2m$ 的小球。小球可在杆与竖直方向所确定的平面内摆动，两面墙之间的距离足够大。

1. 若小球偏离竖直方向的最大角度为 $30^\circ$，求小球到达最大摆角时小环的加速度大小以及小球相对地面的加速度大小。
2. 若摆角很小，求系统的振动周期。

# 第 4 题

一个质量为 $M$、半径为 $r$ 的中性孤立导体球固定在 $x$--$y$ 平面的原点。一个质量为 $m\ll M$、电荷量为 $q$ 的点电荷，从 $x$ 轴负方向的远处以速度 $v_0$ 沿直线 $y=l$ 入射，其中 $r\ll l$。忽略感应电荷移动造成的能量损失，忽略相对论、电磁辐射以及万有引力。

3. 当 $v_0$ 较小时，点电荷可能被导体球俘获。求临界入射速度 $v_c$。

# 第 5 题

水平面上固定一个半径为 $R$ 的光滑圆筒。圆筒中心固定一根质量和原长均可忽略、劲度系数为 $k$ 的轻弹簧，弹簧另一端连接质量为 $m$ 的光滑质点。质点只能在圆筒内部运动。碰撞均为完全弹性碰撞。

1. 将质点置于 $x_0=12R/13$、$y_0=0$ 处，并给它沿 $+y$ 方向的初速度。若要求质点始终不与圆筒碰撞，最大初速度写成

   $$v_{\max}=\alpha_1\sqrt{\frac{kR^2}{m}},$$

   求 $\alpha_1$。
2. 若初速度大于 $v_{\max}$，并要求碰撞后轨迹闭合，且各条轨迹“边”除公共“顶点”外不相交，所有可能轨迹中顶点数最多为多少？
3. 若闭合轨迹有 $4$ 个顶点，初速度写成

   $$v_4=\alpha_4\sqrt{\frac{kR^2}{m}},$$

   求 $\alpha_4$。
4. 在第 3 问条件下，运动周期写成

   $$T=\beta_1\sqrt{\frac{m}{k}},$$

   求 $\beta_1$。

![图 5-1　圆筒内由中心弹簧约束的二维质点运动。](../figures/question-05.png)

# 第 6 题

以下各问均在非相对论框架内讨论，并取

$$\frac{1}{\varepsilon_0\mu_0}=c^2.$$

1. 基础场分布：
   1. 真空中有一无限大均匀带电平面，面电荷密度为 $\sigma$，平面为 $x$--$y$ 平面。求电场分布。
   2. 真空中有一沿 $z$ 轴的无限长均匀带电直线，线电荷密度为 $\lambda$。求距导线 $r$ 处的电场强度。
   3. 上述无限大带电平面以速度 $\bm v=v\hat{\bm x}$ 运动。求电场和磁场分布，并用 $\bm E$ 表示 $\bm B$。
2. 静止参考系中存在

   $$\bm E=E_x\hat{\bm x}+E_y\hat{\bm y}+E_z\hat{\bm z},$$

   且 $\bm B=0$。另一参考系以速度 $\bm v=v\hat{\bm z}$ 运动。求低速近似下该系中的 $\bm E'$ 与 $\bm B'$。
3. 沿 $z$ 轴放置线电荷密度为 $+\lambda$ 的静止正电荷，同时线电荷密度为 $-\lambda$ 的负电荷以速度 $\bm v=v\hat{\bm z}$ 运动。
   1. 求静止观察者看到的距轴线 $r$ 处的 $\bm E$ 与 $\bm B$。
   2. 另一观察者以 $\bm v=v\hat{\bm z}$ 运动。若仍按经典速度叠加，求其看到的 $\bm E'$ 与 $\bm B'$。
   3. 有一电荷量为 $q$ 的质点与运动观察者共同运动。为了使两个参考系计算出的质点受力相同，设只在运动参考系中额外出现线电荷密度 $\Delta\lambda$。求 $\Delta\lambda/\lambda$。

# 第 7 题

低压氢灯产生的可见光谱中有一条波长为 $486.1\,\mathrm{nm}$ 的蓝绿色谱线。试求：

1. 一个该谱线光子的能量，用电子伏特表示。
2. 放出该光子时，氢原子初态、末态分别处在第 $i$ 激发态和第 $f$ 激发态，求 $i,f$。基态记为第 $0$ 激发态。
3. 电子从初态跃迁到末态的过程约持续 $1.5\times10^{-8}\,\mathrm{s}$。根据能量—时间不确定关系，估算谱线的最小频宽。
4. 为估计热运动造成的多普勒展宽，设一群氢原子只沿光线进入分光计的方向作一维运动，速率最大为 $700\,\mathrm{m/s}$。求观察到的该蓝绿色谱线总频宽。
5. 静止氢原子的谱线频率为 $\nu_0$。若氢原子沿观测方向的速度满足一维麦克斯韦分布，热力学温度为 $T$，求频偏 $\Delta\nu$ 的方均根值 $\Delta\nu_{\mathrm{rms}}$。

# 第 8 题

在光滑水平地面上有一个倒扣的箱子，内部长度为 $l$，质量为 $M$。箱内有一个质量为 $m$ 的小球，初始时小球位于箱内右壁处，箱与小球均静止。小球与箱壁之间的碰撞均为完全弹性碰撞。自 $t=0$ 起，对箱子施加恒定水平外力 $F$。

1. 求在

   $$t=5\sqrt{\frac{Ml}{F}}$$

   时，小球与箱壁已经发生的碰撞次数。
2. 求该时刻小球相对地面的位移。
