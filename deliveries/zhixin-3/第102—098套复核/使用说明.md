# 使用说明

直接阅读各套PDF即可。每套均有题面、学生详解、教师备课三个版本；完整目录可移动，latex中的图路径使用相对路径。

图稿源文件每个TikZ图前有编号和输出名称注释；question-xx为题面图，solution-xx为解析图。最终版采用矢量PDF插图，PNG供Markdown阅读。

重建需要Python 3、PyMuPDF、Pillow，以及命令行可用的XeLaTeX、Pandoc、qpdf和中文TeX环境。现有PDF无需这些依赖。新运行生成的日志和中间文件会写入各套build目录。

文字以各套markdown目录中的教师备课稿为主，学生稿取前五模块，题面从question-start/question-end标记之间提取。teacher-only-start/teacher-only-end之间的补充仅进入教师版。保留这些标记和每题九模块标题。

在本目录运行：

```sh
python3 重新生成.py 102 --documents
python3 重新生成.py 102 --figures --documents
```

一次重建五套：

```sh
python3 重新生成.py 102 101 100 99 98 --figures --documents
```

也可直接在某套latex目录用XeLaTeX编译已有文档。修改Markdown后，应使用主稿同步方式生成，避免三个版本内容不一致。不同TeX或字体环境可能改变分页；重新生成后须检查新PDF及更新复核证据。

验证目录保存这次的数学核验、编译及页面检查记录、全页联系表和放大页。数学核验脚本依赖NumPy、SciPy、SymPy，可单独运行；它核验模型主要结果，不代替对改稿的文字和图片审读。
