# 第 1 题

一根质量为 $m$、长度为 $L$ 的均匀细棒，可绕通过中心 $O$ 的水平轴在竖直面内自由转动。开始时细棒静止于水平位置。质量为 $m/3$ 的孙鹏（可视为质点）从棒上方 $h$ 高处由静止下落，在距棒右端 $L/4$ 处抱住细棒，随即沿棒爬向右端。细棒绕 $O$ 轴的转动惯量为 $I_0=mL^2/12$。

1. 若碰撞时间极短，求碰撞后细棒开始转动的角速度大小。
2. 爬行过程中细棒以恒定角速度转动，求孙鹏相对细棒的爬行速度大小。
3. 自孙鹏落到棒上时计时，经过 $t$ 后（$t$ 小于细棒转过四分之一周所需时间），求孙鹏到转轴 $O$ 的距离。
4. 若要求细棒转到与水平方向成 $30^\circ$ 时，孙鹏已进入距右端不超过 $L/8$ 的区域，求下落高度 $h$ 的范围。
5. 在第 4 问的临界情形下，细棒转到 $30^\circ$ 时孙鹏恰好距右端 $L/8$。此刻质量为 $2m/3$ 的黄俏以竖直速度 $v$ 下落，在距棒中心 $3L/16$ 处抱住细棒，细棒随即停止转动，求 $v$。
6. 随后孙鹏仍以原速向右端爬。若要求细棒保持静止，黄俏应以多大速度向另一端爬行？

# 第 2 题

一艘总质量为 $m_0=1.0\times10^4\,\mathrm{kg}$ 的飞船绕地球沿椭圆轨道运动。某瞬间飞船到地心的距离为地球半径的两倍，即 $r_0=2R_E$；飞船速度为 $v_0=6.5\times10^3\,\mathrm{m/s}$，速度方向与飞船—地心连线的夹角为 $60^\circ$。已知

$$R_E=6.5\times10^6\,\mathrm m,\qquad M=6.0\times10^{24}\,\mathrm{kg},\qquad G=6.67\times10^{-11}\,\mathrm{N\,m^2/kg^2}.$$

1. 求飞船—地球系统的机械能以及飞船相对地心的角动量大小。
2. 求近地点、远地点到地心的距离。
3. 求飞船的绕行周期，以小时表示。
4. 现要使飞船从该位置逃离地球引力场。采用最省燃料的方式，使喷气方向与飞船瞬时速度相反。喷气时间可忽略，燃料完全转化为气体，气体相对飞船的喷出速度大小为 $v_x=2.0\times10^3\,\mathrm{m/s}$。求至少消耗的燃料质量。

# 第 3 题

**希尔球与洛希极限**

1. 质量为 $M$ 的行星以角速度 $\omega$ 自转，求同步卫星轨道半径。
2. 行星为半径 $R$、密度 $\rho_M$ 的均匀球体；卫星也均匀，密度为 $\rho_m$。当卫星表面自引力与行星产生的潮汐力相等时，卫星趋向碎裂并可能形成行星环。按此模型求洛希极限。
3. 考虑卫星公转与行星自转同向。为什么轨道高于同步轨道的卫星会逐渐远离行星，而低于同步轨道的卫星会逐渐靠近行星？作定性说明。
4. 质量为 $M$ 的行星绕质量为 $M_0$ 的恒星作半径为 $r_0$ 的圆周运动，且 $M_0\gg M$。卫星在行星附近的希尔球内不会被恒星夺走。求希尔球半径的近似表达式。
5. 水星的希尔球半径 $R_h\approx1.7\times10^8\,\mathrm m$，同步轨道半径 $R_s\approx2.4\times10^8\,\mathrm m$，洛希极限 $R_r\approx3\times10^6\,\mathrm m$。判断水星能否长期拥有卫星和星环，并说明原因。
6. 土星的洛希极限与同步轨道半径很接近。判断土星能否拥有星环，并说明原因。

# 第 6 题

体积为 $V$ 的均匀电介质，内能为 $U=CT$，其中 $C$ 为常量。电极化率在所研究温区内满足

$$\chi_e=\chi_0+\alpha T,$$

因而极化强度为 $P=\chi_e E$。忽略体积变化。外电场作用下，当极化强度改变时，外电场对介质所做元功按题设约定为 $\delta W_{\rm on}=-EV\,\mathrm dP$。系统经历以下准静态循环：

1. 初态为 $(E_1,T_1)$；
2. 在温度 $T_1$ 下等温减小电场至 $E_2$；
3. 保持 $E_2$ 不变，使温度降至 $T_2$；
4. 在温度 $T_2$ 下等温增大电场至 $E_1$；
5. 保持 $E_1$ 不变，使温度升回 $T_1$。

设 $E_1>E_2>0$、$T_1>T_2$，求此循环的热效率。

# 第 7 题

一束单色激光近乎垂直入射到厚度为 $a$、折射率为 $n$ 的平行玻璃板。空气到玻璃界面的振幅透射、反射系数分别为

$$t=\frac{2}{n+1},\qquad r=\frac{1-n}{1+n};$$

玻璃到空气界面的相应系数为

$$t'=\frac{2n}{n+1},\qquad r'=\frac{n-1}{n+1}.$$

入射光复振幅为 $u_0$，真空波长为 $\lambda_0$。

1. 求直接反射光的复振幅。
2. 求在玻璃板内共经历三次反射后射出的反射光复振幅。
3. 求所有反射光相干叠加后的总复振幅。
4. 求反射光完全相消时玻璃板厚度 $a$ 的最小正值。
5. 求光强透射率的最小值 $T_{\min}$。

# 第 8 题

“观测”通常指同一参考系时刻物体的状态；“看见”则由同一时刻到达相机的光线组成。物体不同部位到相机的距离不同，因此照片对应的各光线一般不是同时发出的。

1. 一根静长为 $l$ 的细杆平行于 $y$ 轴，并相对地面系 $S$ 以速度 $\beta c$ 沿 $+x$ 方向运动。相机静止在 $S$ 系的 $y$ 轴上，镜头对准原点且离原点足够远。相机拍到细杆经过原点附近时，照片中两端 $A$、$B$ 是否重合？画出主视图并标出相应长度。
2. 将细杆换成静止边长为 $l$ 的立方体，其三条共点棱分别平行于坐标轴。画出相机拍到的主视图并标出相应长度。
3. 将细杆换成静止半径为 $r$ 的球。证明照片轮廓是半径为 $r$ 的圆而不是椭圆，并指出照片最左、最右两点分别对应球面上的哪些点。可用球的共动系中相应半径与 $+x$ 方向的夹角表示答案。
