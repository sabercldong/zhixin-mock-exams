# 使用说明

每套的PDF目录保存试卷、学生详解、教师备课。markdown保存文字，latex保存可直接编译的文档及模板，figures保存题面图、解析图的矢量PDF、PNG和TikZ源文件。文档图路径为相对路径，整套目录可移动。图稿以每套的“图稿源文件.tex”为主稿，独立.tikz是对应片段副本，修改时须同步主稿。

修改文字以教师备课Markdown为主稿。question-start/question-end标出题面；小写teacher-only-start/teacher-only-end标出的补充只进入教师版。必要推导进入学生解析；小写标记区用于仅教师版的补充。每题九个模块标题也须保留；脚本同步题面和学生版的前五模块。每题之间保留一次手动分页。

重建需要Python 3、PyMuPDF、Pillow、Pandoc、qpdf、XeLaTeX及所用中文字体。现有PDF可直接阅读。修改图稿后先重建图，再重建文档：

```sh
python3 重新生成.py 53 --documents
python3 重新生成.py 53 --figures --documents
python3 重新生成.py 57 56 55 54 53 --figures --documents
```

也可在某套latex目录直接用XeLaTeX编译文档。中间文件写入build目录。改稿后必须检查新的分页、图文对应和物理结论；本次验证记录只对应交付终稿的SHA-256。

验证目录保存逐题审读记录、数学交叉核验、文字润色、编译和页面检查、全页总览、放大页与图稿总览。数学核验可运行“验证/数学核验/check_math.py”，需要NumPy、SciPy、SymPy。check_math.py包含40题关键结果组；check_supplements.py包含38组新增推导和变式核验，并依赖同目录的collision_models.json。脚本核对列出的关系，完整推导另经逐题审读。
