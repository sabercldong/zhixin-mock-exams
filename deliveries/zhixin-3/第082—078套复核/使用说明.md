# 使用说明

每套的PDF目录保存试卷、学生详解、教师备课。markdown保存文字，latex保存可直接编译的文档及模板，figures保存题面图、解析图的矢量PDF、PNG和TikZ源文件。文档图路径为相对路径，整套目录可移动。

修改文字以教师备课Markdown为主稿。question-start/question-end标出题面；小写teacher-only-start/teacher-only-end标出的补充只进入教师版。原有大写TEACHER_ONLY标记是历史标记，保留原样，勿与小写标记混用。每题九个模块标题也须保留；脚本同步题面和学生版的前五模块。每题之间保留一次手动分页。

重建需要Python 3、PyMuPDF、Pillow、Pandoc、qpdf、XeLaTeX及所用中文字体。现有PDF可直接阅读。修改图稿后先重建图，再重建文档：

```sh
python3 重新生成.py 80 --documents
python3 重新生成.py 80 --figures --documents
python3 重新生成.py 82 81 80 79 78 --figures --documents
```

也可在某套latex目录直接用XeLaTeX编译文档。中间文件写入build目录。改稿后必须检查新的分页、图文对应和物理结论；本次验证记录只对应交付终稿的SHA-256。

验证目录保存逐题审读记录、数学交叉核验、文字润色、编译和页面检查、全页总览、放大页与图稿总览。数学核验可运行“验证/数学核验/run_checks.py”，需要NumPy、SciPy、SymPy、mpmath。一个脚本包含40题关键结果组和17项补充核验；它核对列出的关系，完整推导另经逐题审读。
