# 使用说明

各套PDF目录有试卷、学生详解、教师备课三个版本。markdown保存文字，latex保存可直接编译的文档与模板，figures保存80幅矢量PDF和PNG以及TikZ源文件。整套目录可移动，文档的图路径使用相对路径。

修改文字时以教师备课Markdown为主稿。question-start/question-end界定题面；teacher-only-start/teacher-only-end之间的补充只进入教师版。保留每题九模块标题和这些标记，脚本会同步题面与学生版的前五模块。修改图时编辑图稿源文件，各图前的编号注释决定拆分名称。

重建需要Python 3、PyMuPDF、Pillow，以及命令行可用的XeLaTeX、Pandoc、qpdf和中文TeX字体环境；现有PDF可直接阅读。运行命令：

```sh
python3 重新生成.py 97 --documents
python3 重新生成.py 97 --figures --documents
python3 重新生成.py 97 96 95 94 93 --figures --documents
```

也可在某套latex目录直接用XeLaTeX编译已保存的文档。重建的中间文件写入build目录。文字或图稿修改后须检查新的分页与图文对应；旧的验证记录只对应本次交付的最终文件。

验证目录保存数学核验、语言润色、编译和页面检查、全页总览及放大页。数学核验脚本依赖NumPy、SciPy、SymPy，可单独运行。每份PDF的SHA-256及文件校验清单可用于核对交付版本。
