# 第018套第8题核验备忘（内部，非正式交付）

2026-10-08重新实际读取原题第3页及手写第8页左栏。两问完整。静质量均为m0，电荷为±Ze；r0是粒子间距，各自绕质心半径r0/2。题设明确只考虑瞬时静电库仑力、不考虑电磁辐射，动量采用p=γm0v，总角动量L=nℏ。保留这个半经典模型，不将其宣称为完整相对论电磁理论或真实量子基态。

手写两方程正确：L=2*(r/2)*p=r*p；单粒子匀速率圆周动量矢量以角速度ω=2v/r旋转，故|dp/dt|=ωp=2pv/r=KZ²e²/r²。消元时先除出v=A/(2L)，A=KZ²e²，速度为正且必须小于c。取β=A/(2Lc)，p=m0cβ/sqrt(1−β²)，r=L/p=L*sqrt(1−β²)/(m0cβ)=2L²*sqrt(1−β²)/(m0A)。一般n取L=nℏ，基态n=1：

r0=ℏ*sqrt(4−α²Z⁴)/(m0cαZ²)，α=Ke²/(ℏc)。

手写根式形式与该式相同，无需纠正结论；须补每一步消元、负根筛选和严格条件0<αZ²<2。Z>0且若取正整数，有Z≤16，不能把Z=0、β=1或r=0计为圆轨道。临界Z=sqrt(2/α)≈16.56，不是完整量子电动力学临界电荷的普遍定律。

独立路线：质心系瞬时相反动量，相对坐标r与共轭p构成总角动量L=r×p。固定L的总能量H(r,p_r)=2sqrt[m0²c⁴+c²(p_r²+L²/r²)]−A/r；圆轨道要求p_r=0且∂H/∂r=0。直接从导数求根，与上述力和角动量消元交叉验证。圆轨道总能量2m0c²sqrt(1−β²)，低于分离静止能量2m0c²。固定L时H''>0；径向小振动κ/ω=sqrt(1−β²)。这些作为教师深入核验，不把相对速度2v当作狭义相对论速度合成的测量值。

非相对论极限r0≈2ℏ²/(m0A)，正好对应约化质量m0/2；有限相对论时不能机械把m0换成m0/2后套一个相对速度公式。若A=2cL，小r能量趋0但无正半径驻点；若A>2cL，小r能量无下界。这解释严格不等式，但只属于题设点粒子静电模型。圆轨道稳定与真实量子基态不是同一概念。
