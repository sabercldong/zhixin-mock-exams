# 蔡题 101｜图稿索引

## 一、图稿保存形式

- `蔡题101_图稿源文件.tex`：全部 TikZ 可编辑源代码。
- 同名 `.pdf`：供 LaTeX 成品使用的矢量图。
- 同名 `.png`：供 Markdown 与 Obsidian 预览使用。

## 三、图形核验项目

1. 图中变量与正文一致；
2. 箭头方向与正方向约定一致；
3. 电感、电容和支路电流标签与原图一致；
4. 几何尺寸 $l$、$h$、$x$ 的定义与题面一致；
5. 每幅图均通过 XeLaTeX 独立编译；
6. PDF 成品使用矢量图，Markdown 使用 PNG 预览图。
