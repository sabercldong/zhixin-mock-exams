# 第029套整理文件

正式成品在 output 中，共试卷版、学生详解版、教师备课版三个 PDF。可编辑正文在 markdown 中，TikZ 与单图矢量 PDF、PNG 在 figures 中。

本套已完成逐套验收：试卷版9页，学生详解版67页（正文66页），教师备课版76页（正文75页）；32幅重绘图，8题独立核验通过。最终页数与字符统计见核对记录.md和build/strict-quality.json。三版本152页总览及34页高清复核记录已保存。

日常修改入口为 markdown/蔡题029_教师备课.md。学生版由其前五模块生成，试卷版由各题题干生成，不要分别修改派生版本后期待自动回写。教师版每题九模块，学生版每题五模块。

重建命令：

    python3 scripts/build_all.py

这会重新核验计算、渲染图稿、生成 Markdown 派生版本、编译三个 PDF 并进行技术检查。既有源文件、预览、脚本均保留，不清理或移动原始 PDF。

drafts 是本轮逐题工作稿。只有明确需要用它覆盖教师主文件时，才使用：

    python3 scripts/build_all.py --from-drafts

图稿修改入口为 figures/题01_图稿源文件.tex 至题08_图稿源文件.tex。每份图稿含该题的全部独立 TikZ 图片；渲染脚本按既定名称导出单图，正文中只显示图像。

版式固定为 A4、12pt、四边22mm、行距1.24、段距0.35em。仅八题之间使用七处分页。有限逻辑块标记只用于保持相关公式与结论相邻，不用于扩页。

build/strict-quality.json 给出实际页数、三种字符口径、各题正文量、101同口径对照、原件校验和和八题验证结果。自动技术检查不能替代实际页面审阅；每次重建后若 PDF 校验和改变，旧的人工审阅记录不再授权新成品通过验收。

preview/formal 保留全部页面总览与高清检查页；preview/figures 保留32幅图的逐题总览。核对记录.md 保存资料对应、物理修正与最终验收情况。
