| 1 柱形电流导线 | 定义κ=μ₀jIl/2、ω²=κ/m。内区F=−κρ，外区F=−κr²/ρ；U(r)=0，内区U=κ(ρ²−r²)/2、外区U=κr²ln(ρ/r)。不进入条件v₀²≥2κr⁴ln(ρ₀/r)/[m(ρ₀²−r²)]，等号触边。正交出口sin²α=(v₁²+ω²r²)/(2v₁²)，实际入区要求v₁>ωr；原解把等号列入时须补明它是边界圆轨道，不代表先入区再出区。v₁=√3ωr给α=54.735610°、ωtₑ=π/4。未把稳恒给定电流的安培力误当作不做功的qv×B。 |
| 2 速度变换 | 原题“同速且平行”须区分同向和反向，同向同速在任何惯性系仍同速度。反向且非退化时V²=v₀²/[1+(v₀²/c²)sin²θ]，sinθ≠0。原手写速度变换分母的符号按两粒子的原纵向速度分别校正；最终直角速度式回代成立。空间交点对应不同事件，示例Δt′=d/(γV V)≠0；不能声称碰撞。另核对截距变换、未来观察线段及三维异面情况。 |
| 3 独轮车 | 总长2a、焦距a/√3，深度y=√[2(a²−x²)/3]，d₁,₂=a±x/√3。补明准静态和r≪a条件；原题没有有限运动速度、转动惯量及重心高度，不能构造唯一动态答案。两侧正张力仅在|x|<a/√3成立；右移所需驱动转矩为−2mgrx/√[2(a²−x²)]，方向顺时针。μmin=|ln(T₂/T₁)|/φ，φ用弧度；x=0.3a时μmin=0.410126819。焦点极限T₁→0而φ→2π/3，任何有限摩擦系数不能覆盖全程。先给重心水平偏移，只有给重心距离才给倾角。 |
| 4 双电容充电 | 源功2CU₀²、末态储能CU₀²、总热CU₀²。由消元方程乘q̇₂并积分，右热CU₀²/6，左热5CU₀²/6，比5:1。指数解、积分和节点ODE分别检查。相同电容、不同电阻时Q右=R₂CU₀²/[2(2R₁+R₂)]。不同电容时Q右=R₂C₂²U₀²/[2(R₁(C₁+C₂)+R₂C₂)]。未把转移电荷比平方当作热量比。 |
| 5 三电荷 | 任意不同点共线初态都是固定直线分支，原解只列非共线特殊构型时不完整。非共线中心构型满足η₁d₂₃³=η₂d₃₁³=η₃d₁₂³，ηᵢ=Qᵢ/mᵢ；对边比1:2^(−1/3):3^(−1/3)。质心按质量求。构造rᵢ=sRᵢ、s̈=A/s²证明全过程，A=U₀/I₀，ṡ²=2A(1−1/s)。固定直线分支说明与几何可实现性均补全；用不等质量(1,2,4)、电荷质量比(1,2,3)完整库仑ODE交叉核验。 |

## 验收办法

verify_physics.py实际运行96项主核验和8组补充核验，全部通过；包含19组谐振轨道、165组非退化速度变换、151个钢丝位置、六组电路热积分ODE、不等质量三体完整ODE、六组有限质量转折、两组焦距的164条光线及301点极坐标磁场运动。报告为physics_verification.json，不是用占位“通过”代替计算。

八份主稿每题均有九个固定标题；学生抽取前五模块，试卷抽取题面及题图，教师保留全部九模块。每题四个完整变式用逻辑块保持题干与解答同页。三版均只在题与题之间手动换页，共七处；没有逐页强制空白或为凑页调整字号。公式引导句与公式连排，长公式改独立行，希腊符号使用数学字体。

40幅独立矢量图与八份多图源一致。所有原页、最终全页总览、重点高清页及八张配图总览均需实际查看后才置完成标志。render_full_review.py仅生成图像，生成本身不表示审读完成。实际审读记录绑定最终文件SHA256，后续重建会清除完整验收标志。
