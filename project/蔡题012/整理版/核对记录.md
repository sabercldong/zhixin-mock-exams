| 1 有限光速人影 | 地面迟滞式2X−q=β√(h²+q²)。X=h/2、β=0.6时有向影长−0.1380857945h，距离大小0.1380857945h。人系D−s=β√(h²+4s²)，D=h/2给两个合法根s/h=−0.1159116218、−2.1568156509，均满足未平方式。题面显式约定取与脚相连的近端影区；远端不是伪根，依赖匀速世界线延拓历史。近端坐标速度0.8230465247c，而影长正在缩短；远端坐标速度−3.5503192520c属于几何影界。两系相距h/2对应不同事件，不能只作长度收缩。另给一般身高比例、分支折叠与β=1/2连续极限。 |
| 2 抛转杆 | 冲量后质心速度v₀/2，角速度v₀/l；近返回高度匀速下降模型要求v₀²/(8g)≫l。以材料坐标推导扫掠雅可比包络，结合端点轨迹裁剪边界。无标记杆竖向周期H=πl/2；左空隙临界θ+sinθ=π/2，θ=0.8317111936，xc=0.1631939854l。概率需要均匀返回相位，原题单次运动没有给出随机分布，因此题面明确补充该假设。x=0.2l给P=1，x=0.8l给P=0.1240270627；右侧必须检查内部驻点与端点，不能只算端点。 |
| 3 方轮车 | 保留题给I=ma²/6，不改为均匀方板惯量。按无耗散纯滚动解释原题滚动几何，切向静约束不等于恒为零。总动能K=(M+2m)V²/2+Iω²，轮轴等高给反悬链线f=a[1−cosh(x/a)]，周期p=2a ln(1+√2)=1.762747174a。两轮在同一平面、同相安装时d=np，且任意相位不相交需d≥2√2a，所以最小d=2p=3.525494348a。原路面不适配六边形；重设计后p₆=√3a ln3。M=4m时ωb/ωt=√(19/37)、Vb/Vt=√(38/37)，总动能守恒。 |

| 5 倍增阻感网络 | 每级先串联2ⁿR，随后并联纵向串联2ⁿR与2ⁿL及倍增尾网。Z=R+(R+jωL)∥2Z，物理解Z=[3R+jωL+√(17R²−ω²L²+14jRωL)]/4。直流Z/R=(3+√17)/4，低频有效电感L(1+7/√17)/4，高频Z≈5R/2+jωL/2。节点比ρ=1−R/Z满足|ρ|<1；峰值电压对应平均功率U₀²Re(1/Z)/2。全级电阻损耗几何求和与端口功率一致。给一般倍率λ>1的自洽式及适用极限，不使用有源负实部根。 |
