# 第007套逐题复核记录

1. 水球采用公开的近轴、完整球面分区模型及n=4/3。水区像位球心右40cm、放大率−1；气泡区像位−10cm、放大率+1/4，环形水区的结论不无条件推广到有限孔径像差。4道变式以光线矩阵、像距与放大率交叉核对。

2. 滚动接触偏移模型η=0.002给出cosθ=0.998、tanθ≈0.0633406，10根滚木对应拉力约62074N、最小静摩擦系数0.06334。压缩量本身不能决定真实耗散，静摩擦也不自动等于μN。4道变式核查几何、受力及模型限制。

3. 环杆约束给出初态aA=aC=g/4、张力1.5mg；速度修正为±3v²/l，张力增加6mv²/l。冲量阶段杆/支座有外冲量，不能把整个体系竖直动量误当守恒。4道变式的约束导数、冲量与加速度均核对。

4. 各向异性气体±x运动的静止壁压力为nγm₀v²；变换观察者后计算同一物理运动壁的受力，不能直接把固定空间面的动量通量当壁压力。无横向粒子则侧壁不受碰撞压力。4道变式核查碰撞事件和不同方向的观察者变换。

5. 本轮将“内膜被外膜吸引”改为净电场应力的解释：同轴均匀外膜在内部的场为零，内膜外向力包含自身其他部位电荷的排斥。压力λ²/(8π²εa²)、λ²/(8π²εb²)，P₂=P₀+pe,b−pe,a<P₀。4道变式核查电荷反号、间隙与固定电压条件。

6. 正离子密度n₀、带电2q；负离子密度2n₀、带电−q，电导率n₀q²(4/k₊+2/k₋)。电中性不抵消常规电流，I=σlU。交流响应另需质量与介电参数；本轮统一“弛豫”用字。4道变式的功率与频率极限已核对。

7. 刚性绝热吹放使用T/T₀=z^(2/3)、P/P₀=z^(5/3)，按出口气体仍携带内能的模型积分冲量，J=(3/4)μν₀w₀。半冲量时压力约初压的60.315%；全部焓转换为射流动能属于另一喷嘴模型。4道变式已按各自条件核对。

8. 四杆几何给出Mθ=10ml²、Kθ=2kl²，与位移坐标My=20m、Ky=4k一致，ω²=k/(5m)。原手写解回弹二次项少一倍的错误仍明确说明。本轮移动H标签避免虚线遮盖。4道变式及初始条件到分部运动的转换已核对。
