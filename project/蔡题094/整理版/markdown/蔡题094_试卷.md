# 第 1 题

质量为 $m$ 的质点在 $x-y$ 平面内运动，受到指向原点的各向同性线性回复力

$$\bm F=-kx\bm e_x-ky\bm e_y.$$

初始时质点位于 $(l,0)$，初速度大小为 $v_0$，初速度方向与 $x$ 轴正方向的夹角为 $\theta$。

1. 求振动周期，并写出 $x(t)$、$y(t)$。
2. 消去时间，写出固定 $\theta$ 时的轨迹方程。
3. 保持 $l$、$v_0$ 不变而让 $\theta$ 任意变化，求质点所有可能到达区域的边界。

# 第 2 题

一个静止、具有七重旋转对称性的花瓣形曲线固定在平面内，中心为 $O$。边长为 $l$ 的正三角形在曲线外侧无滑动滚动；三角形中心 $A$ 的轨迹恰为以 $O$ 为圆心、半径为 $R$ 的圆。

1. 当 $A$ 绕 $O$ 公转一周时，正三角形自转多少圈？
2. 在图示位置，公转角速度为 $\Omega$。用 $R,l,\Omega$ 表示外侧顶点 $P$ 的速度和三角形角速度大小。
3. 以 $O$ 为极点、图示 $OA$ 方向为极轴，用 $R,l$ 和极径 $\rho$ 写出第一瓣曲线的极坐标方程 $\theta(\rho)$。
4. 要求公转一周后三角形恰好恢复初始取向，求 $R/l$ 满足的方程；允许保留一个无量纲定积分。这里“恢复”按正三角形轮廓的 $120^\circ$ 旋转对称等价理解。

计算中可使用

$$\int\frac{\mathrm{d}x}{x\sqrt{(a-x)^2-b^2}}
=-\frac{1}{\sqrt{a^2-b^2}}\ln\left(
\frac{a^2-b^2}{x}-a+
\frac{\sqrt{a^2-b^2}\sqrt{(a-x)^2-b^2}}{x}
\right)+C.$$

# 第 3 题

半径为 $r$、质量为 $m$ 的均匀实心球体均匀带电，总电量为 $q$。

1. 球体以角速度 $\omega_0$ 转动，求角动量大小 $L_0$。
2. 求相应磁矩大小 $\mu_0$。
3. 空间存在 $\bm B=B\bm e_z$。小球自由运动，只受洛伦兹力，不计电磁感应。初态为

   $$\bm v(0)=(v_0,0,0),\qquad \bm\omega(0)=(0,v_0/r,0).$$

   求质心速度与角速度随时间的变化。
4. 小球在水平 $x-y$ 平面上做无滑动滚动，重力沿 $-z$，摩擦足够大。磁场仍为 $\bm B=B\bm e_z$，初态同上。求 $\bm v(t)$ 与 $\bm\omega(t)$。

# 第 5 题

把气球皮视为厚度为 $h_0$ 的薄橡胶球壳，其中 $h_0\ll r_0$。初始气球半径为 $r_0$，外界大气压强为 $p_a$，气球内外压强差为 $p_0$。

1. 橡胶皮在单位长度上的张力为 $\sigma_0$，求 $\sigma_0$。
2. 假设 $\sigma_0$ 保持不变，温度保持为 $T_0$，用气泵缓慢地把定容热容 $C_V=3R/2$ 的理想气体从气球外输送到气球内，使半径从 $r_0$ 增大到 $2r_0$。定义一小段时间内气泵做功为“当前气球内压强乘以流入气体在该压强下的体积”，求最少做功。
3. 进一步吹气时，橡胶体积有小的相对增加量 $\gamma=\Delta V/V_0$，半径相对增加量为 $\alpha=\Delta r/r_0$，且 $\alpha,\gamma\ll1$。求橡胶皮相对厚度增加量 $\beta=\Delta h/h_0$。

# 第 6 题

建立直角坐标系 $x-y-z$。在 $x-y$ 平面放置光心在原点、焦距为 $f_1$ 的足够大理想薄凸透镜 $A$；在 $y-z$ 平面放置焦距为 $f_2$ 的透镜 $B$；在 $z-x$ 平面放置焦距为 $f_3$ 的透镜 $C$。三透镜相互正交并共用光心。第一卦限有点光源

# 第 7 题

3. 筷子质心最低时，筷子中点截面上传递的内力大小。
4. 整个运动中，筷子中点截面承受的最大弯矩。

# 第 8 题

一个夹子由两根质量均为 $m$、长度均为 $L$ 的相同刚性细杆组成，两杆一端铰接。若两杆总夹角为 $\Delta\theta$，铰链产生大小为

$$M=k\Delta\theta$$

的回复力矩，使两杆趋向重合。夹子放在无摩擦水平地面上，只能在图示竖直平面内运动。

1. 对各种参数关系，求两杆均与地面接触时可能的平衡夹角，并判断稳定性。
2. 取

   $$k=4\ \mathrm{kg\,m^2/s^2},\quad g=10\ \mathrm{m/s^2},\quad m=1\ \mathrm{kg},\quad L=1\ \mathrm m.$$

   把两杆压至总夹角 $\pi$ 后由静止释放。判断回合过程中是否会离开地面；若会，求离地时的两杆夹角。
