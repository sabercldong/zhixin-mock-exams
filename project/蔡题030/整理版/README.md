# 第030套

正式成品在 `output`：

- `第030套_试卷版.pdf`：9页（8页正文）。
- `第030套_学生详解版.pdf`：73页（72页正文）。
- `第030套_教师备课版.pdf`：84页（83页正文）。

三版Markdown在 `markdown`，图片引用为相对路径，可供Obsidian阅读和编辑。所有题图及解答图居中，正式PDF采用矢量图。详细统计、物理纠正和审读证据在 `核对记录.md`、`build/strict-quality.json`。

## 编辑与重建

后续编辑入口为 `markdown/蔡题030_教师备课.md`。学生版自动提取每题前五模块，试卷版自动提取题干；不要分别修改三份Markdown后期待它们仍同步。八题的首次编写稿在 `drafts` 保留。

在本目录运行：

```bash
python3 scripts/build_all.py
```

流程为独立计算核验、TikZ编译、学生/试卷提取、Pandoc—XeLaTeX编译、qpdf与严格质量检查、逐页渲染。使用现有运行环境，无需修改第101套或原始PDF。

`--from-drafts` 只用于明确需要从八份工作稿重新汇入教师主文件时。它会以工作稿重建教师主文件；在主文件已有后续修改时不要使用该参数。

改动图形时编辑 `figures/题01_图稿源文件.tex` 至 `题08_图稿源文件.tex` 中对应图页。连续绕线、球面空间结构及符号约定都应一并核验。32幅PNG用于Markdown，32幅单图PDF用于正式文档；源码和编译产物全部保留。

## 人工验收

重建通过不等于人工复审自动完成。编辑后应查看新生成的 `preview/formal` 总览，高清审读变更页及图文衔接，确认内容正确后再更新 `preview/formal/visual-review.json` 的页码与成品SHA-256，运行：

```bash
python3 scripts/quality_check.py
```

只有当前成品与人工审读记录一致时，最终状态才为 `acceptance_pass`。旧审读记录的哈希不会自动授权新版通过。

原始试卷、手写答案及所有辅助源文件保持不动。本套含8题、32幅图；固定101版式，不以拉大行距、空白或未解练习增页。
