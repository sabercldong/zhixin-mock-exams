- 31幅TikZ矢量图及PNG显示图保留在figures/；多图源文件为“题01_图稿源文件.tex”至“题08_图稿源文件.tex”。正文不展示代码。
- Pandoc生成的三份LaTeX及编译PDF、日志保留在build/；固定版式模板位于latex/template.tex。
- 分题初稿在drafts/保留。以后改教师主文件时，不要使用 --from-drafts，否则分题初稿会重新汇入并覆盖主文件。

在本“整理版”目录中运行：

~~~sh
python3 scripts/build_all.py
~~~

该命令使用现有Pandoc—XeLaTeX流程，重新核验计算、重绘图稿、生成三版本并运行技术检查与总览预览。使用已配置的科学Python和TeX编译器，不安装额外运行环境。

内容或图稿修改后，应重新审视实际PDF和更新与PDF校验和一致的preview/formal/visual-review.json，再运行：

~~~sh
python3 scripts/quality_check.py
~~~

技术检查通过而视觉记录未更新时，只标记technical_acceptance_pass_pending_visual_review，不自动称为人工验收通过。核验数值及物理假设也需要随相关推导同步修订。
