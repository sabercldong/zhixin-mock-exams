# 第033套编辑与重建

正式阅读文件为`output`中的试卷版、学生详解版和教师备课版三个PDF。学生版61页（正文60页），教师版80页（正文79页），扉页各一页。

内容主文件是`markdown/蔡题033_教师备课.md`。修改主文件后运行：

```sh
python3 scripts/build_all.py
```

脚本从教师主文件提取学生前五模块及试卷题干，编译18幅TikZ图与三版本PDF，运行逐题独立核验、结构和正文深度检查，并生成全页预览。`build`与`output`PDF必须一致。学生版和试卷版Markdown是生成文件，不直接修改；图形修改对应`figures/题XX_图稿源文件.tex`。

`drafts`及`preview/working`为保留的编写阶段材料，不是正式交付版本。仅在明确需要重新导入全部工作稿时才使用`--from-drafts`，以免覆盖后续对教师主文件的编辑。

自动技术检查不能代替视觉审读。`preview/formal/visual-review.json`记录已实际审读的正式PDF校验值；重新编译后若校验值变化，需要重新审查受影响页并更新记录。最终验收见`核对记录.md`与`build/strict-quality.json`。

原始试卷、手写答案和既有辅助文件均保留，不执行清理或移动。
