# 第102套整理版说明

## 文件组成

- `markdown/蔡题102_试卷.md`：重新排版的纯试卷。
- `markdown/蔡题102_学生详解.md`：题型定位、知识点、物理图像、解题入口和逐步解析。
- `markdown/蔡题102_教师备课.md`：在学生版核心解析基础上增加关键洞察、易错点、课堂讲解建议和变式训练。
- `markdown/蔡题102_核验记录.md`：手写答案比对、订正项与独立核验。
- `markdown/蔡题102_图稿索引.md`：题图和解答图的对应关系。
- `figures/`：TikZ 源文件、矢量 PDF 和 PNG 预览。
- `output/pdf/`：试卷、学生详解、教师备课三套最终 PDF。

## 构建顺序

1. 修改教师版和试卷版 Markdown。
2. 运行 `scripts/prepare_documents.py` 同步生成学生版，并统一各版结构。
3. 编译 `figures/蔡题102_图稿源文件.tex`，拆分并更新独立图稿。
4. 运行 `scripts/build_documents.py` 生成三套 LaTeX 主文件。
5. 使用 XeLaTeX 编译三个主文件。
6. 运行 `scripts/verify_answers.py` 执行答案核验。

原始试卷与手写答案保持不变。

教师版已按第101套的讲解密度返工：解析中补入公式来路、正负号说明、物理解筛选和极限检查；课堂讲解建议改为可直接备课使用的讲解流程；变式训练补充训练目的和迁移方向。学生版同步保留扩写后的核心解析。当前学生详解为44页，教师备课为52页。
